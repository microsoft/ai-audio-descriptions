# Deployment Files

This directory contains the infrastructure and deployment files for the AI Audio Descriptions application.

## Quick Start

For setup instructions, please refer to the **"Setup Azure"** section in the [main README](../readme.md).

## Files

- `main.bicep`: Azure Bicep template defining all infrastructure
- `main.parameters.json`: Parameters file for customization
- `setup.sh`: Automated setup script
- `cleanup.sh`: Script to remove all created resources

## Advanced Configuration

You can customize the deployment by modifying parameters in `main.parameters.json`:

- `resourceGroupName`: Name of the resource group (default: `rg-ai-audio-descriptions`)
- `location`: Azure region - must be one of: `westus`, `swedencentral`, `australiaeast`
- `namePrefix`: Prefix for all resource names (default: `aiad`)

## Security Details

- SAS tokens are generated with minimal required permissions (read, write, delete, list)
- Tokens expire after 1 year and can be regenerated by re-running the setup script
- CORS is configured only for localhost development (`http://localhost:5173`)
- No secrets are stored in the Bicep template outputs or source control
